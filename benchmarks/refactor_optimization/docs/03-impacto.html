Volumes

bench_volumes.py stores molecule payloads two ways and times the same reads on both: SQLite blobs (RT) against append-only volumes (serial: HT no fsync, H fsync per shard; parallel: VP the parent writes, VC one segment per chunk, PJ a real ms_flow job whose rows carry Payloads, PJZ/PJD the same with zstd, without and with a dictionary per series; PS the real PayloadStore with one fsync per commit, PSN the same without it). Warm reads run right after the import, with the data in the page cache; cold ones run after fsync and posix_fadvise(DONTNEED) on every file, so they come from the disk. A blank cell was not measured (the 2026-10-15 run has no cold reads). Plan: 08-plan-volumenes.md.

How this was measured

Workload. Empty tasks, so what is timed is the orchestration alone: with real tasks the same cost is added on top of the task time. Every run starts from a new state file and a temporary HOME.

Reading it. The numbers are from one machine and move a few percent between runs; compare columns of this page with each other, not with another machine.

Record a step: python -m benchmarks.refactor_optimization.bench --label <step>, add its line to STEPS in report.py, then python -m benchmarks.refactor_optimization.report.
